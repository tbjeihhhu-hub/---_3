# قعدة الربع — Flutter MVP

مشروع أولي قابل للتشغيل للعبة دومنة ضد الكمبيوتر، مع مراحل تجريبية وشخصيات وحوارات نصية.

## المتطلبات
- Flutter SDK حديث (Dart 3.3 أو أحدث)
- Android Studio أو VS Code مع Flutter extension
- Android SDK لتشغيله على جهاز أو محاكي

## التشغيل
1. فك ضغط المشروع.
2. افتح مجلد `qudat_al_rub_flutter` في Android Studio أو VS Code.
3. من الطرفية داخل المجلد نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```
4. لإنشاء APK:
   ```bash
   flutter build apk --release
   ```
   الملف الناتج عادةً: `build/app/outputs/flutter-apk/app-release.apk`

## الموجود حالياً
- شاشة رئيسية باسم اللعبة وحقوق علاوي ال حمادي.
- لعبة دومنة مبسطة ضد الكمبيوتر.
- ثلاث شخصيات/مراحل تجريبية.
- حساب جولات وفوز وخسارة.
- واجهة عربية مناسبة كبداية للموبايل.

## حدود النسخة الأولى
- الرسوم الحالية واجهة 2D باستخدام Flutter ورموز تعبيرية؛ ليست شخصيات 3D متحركة.
- الحوارات مكتوبة وليست تسجيلات صوتية.
- منطق الدومنة مبسط، وليس محرك دومنة تنافسياً كاملاً.
- لا يوجد حساب مستخدم أو اتصال إنترنت أو لعب جماعي أو قاعدة بيانات.

## طريق الوصول إلى نسخة 3D بصوت عراقي
لشخصيات 3D متحركة ومشهد مقهى، الأنسب استخدام محرك ألعاب مثل **Unity** أو **Godot** كمشهد اللعبة، مع Flutter للقوائم/الحسابات إذا لزم. يمكن أيضاً بناء اللعبة بالكامل بمحرك واحد لتقليل التعقيد.
- الشخصيات والأنيميشن: نماذج 3D مرخّصة أو مصممة خصيصاً.
- الصوت: تسجيل الحوارات باللهجة العراقية، أو خدمة توليد صوت مناسبة مع مراجعة الترخيص.
- أونلاين مستقبلاً: خدمة مثل Firebase أو Supabase للحسابات/التخزين، وخادم موثوق للعب الجماعي عند الحاجة.
- النشر: اختبار الأجهزة، أيقونة، سياسة خصوصية عند جمع بيانات، ثم بناء APK/AAB.
